# My-Portfolio Website

This is a personal portfolio website built using **React**, **Tailwind CSS**, and **EmailJS**. It showcases my skills, projects, and contact information in a clean, responsive, and modern layout.

## 🚀 Live Demo

Check out the deployed website here:  
👉 [https://prem-aman.vercel.app/](https://prem-aman.vercel.app/)

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Styling:** Tailwind CSS  
- **Email Integration:** EmailJS  
- **Deployment:** Vercel  

## 📂 Features

- Responsive and modern design  
- Projects section to showcase your work  
- About section with brief bio  
- Contact form powered by EmailJS  
- Deployed and hosted via Vercel

git clone https://github.com/your-username/My-Portfolio.git
